# CodeMenu
Sharing CodeMenu1, an open-source GitHub repository dedicated to knowledge sharing across core Machine Learning concepts, statistical modeling, and data analytics.

Whether you are looking to review foundational math or explore end-to-end ML applications, this collection covers a wide range of topics with practical code and Jupyter notebooks (.ipynb):

Computer Vision & Linear Algebra: Face Recognition using EigenFaces, Eigenvalues, and Principal Component Analysis (PCA).

Predictive Analytics & Healthcare: Diabetics Prediction using diagnostic measures and Logistic Regression.

Regression & Real Estate: Real Estate Price Prediction using advanced modeling techniques.

Market Basket Analysis: Association Rule Mining to identify frequently bought together items.

Natural Language Processing (NLP): Spam Filtering and Topic Modeling algorithms.

Data Engineering & Clustering: K-Means Clustering, essential SQL queries, and hands-on ML lab exercises.
